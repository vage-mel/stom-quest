# Стоматологический квест · офлайн

Всё в одном `index.html` (иллюстрации SVG, без Google Fonts). **Интернет не нужен.**

## Как отдать, когда сеть глушат

**Лучший способ:** скинь ей файл `index.html` (Telegram / Bluetooth / AirDrop / флешка), пока есть хоть какая-то связь или рядом.

На телефоне:
- **iPhone:** Файлы → открыть `index.html` в Safari / Chrome
- **Android:** «Файлы» / «Загрузки» → открыть в Chrome

Можно заранее открыть один раз по ссылке (если задеплоишь) — браузер закэширует через service worker, и потом откроется без сети.

## Деплой (опционально)

Папка `stom-quest` на Netlify Drop / GitHub Pages. После первого визита с интернетом работает офлайн.

## Настройки

В `index.html` блок `CONFIG`: имя, текст в конце.
